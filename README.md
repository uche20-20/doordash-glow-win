# doordash-glow-win

Create a responsive, high-converting landing page for $500 DoorDash Sweepstakes hosted on doordash.reviewgo.xyz.




🎨 Design
	•	Background: Glowing gradient in DoorDash red → orange → white.
	•	Effects: Soft glowing borders, hover animations on buttons.
	•	Mobile-first design, responsive on tablet + desktop.
	•	Floating particles in background for a lively premium feel.




📰 Sections
	1.	Hero Section
	•	Headline: “Win a $500 DoorDash Gift Card 🍔🚗”
	•	Subheadline: “Enjoy free meals & delivery — limited spots available!”
	•	Big glowing CTA button: “Claim My $500 Now” → link to:
https://rewarrdsgiant.com/aff_c?offer_id=455&aff_id=31368
	2.	3 Easy Steps
	•	Step 1: Take the Survey → “Answer a few quick questions about DoorDash.”
	•	Step 2: Complete 3–5 Deals → “Unlock your eligibility.”
	•	Step 3: Get Rewarded → “Receive $500 DoorDash credit instantly.”
	3.	Social Proof (Fake Notifications)
	•	Bottom-left popups with glow. Rotate every 5–8s.
	•	Examples:
	•	“Samantha just claimed $500 DoorDash gift card”
	•	“Brian from Texas secured his $500 DoorDash reward”
	•	“Emily unlocked $500 DoorDash credit”
	•	Each popup has ❌ close button.
	4.	Notice Section
	•	Text with red glowing border:
“⚠️ Available only in US, CA, UK, AU. Limited spots — act fast.”




💻 Tech
	•	Fully responsive (mobile, tablet, desktop).
	•	Fast loading, lightweight animations only.
	•	CTA + notifications must glow and be clickable.
